## Many Lines Make a Curve

- Each hidden neuron contributes **one** linear boundary
- Together they carve the input space into regions
- More neurons = more cuts = tighter boundaries

:::note
The boundary *looks* curved. Up close it is **piecewise-linear**: many straight cuts.
:::
