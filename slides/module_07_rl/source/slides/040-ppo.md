## PPO Learns the Baseline With a Critic

Schulman et al. (2017): **Proximal Policy Optimization** uses an actor and a critic.

:::columns cols="2" gap="34px"
**Actor: the LLM**

Samples responses and learns to increase expected reward.
+++
**Critic: a value estimator**

Predicts expected return from the prompt or a partial response. Learns from observed returns.
:::

For a simple response-level example: $A = R - V_\psi(x)$.

The **critic predicts the baseline**. The **reward source still determines the score**. Full PPO usually estimates advantages over token states.

## PPO Limits How Strongly It Reuses a Batch

Save the policy that generated the samples: $\pi_{\mathrm{old}}$.

Compare current and sampling probabilities for each generated token:

$$r_t(\theta) = \frac{\pi_\theta(y_t \mid x,y_{<t})}{\pi_{\mathrm{old}}(y_t \mid x,y_{<t})}$$

The **clipped objective** stops rewarding further movement in the same direction once the ratio passes a threshold.

This supports a few updates on one batch before collecting fresh samples. It is **not a hard bound** on every probability change.
